# Meu nome é Diogo Amancio 👋

Sou profissional de **Quality Assurance (QA)**, com experiência em testes de software e foco em automação de testes Web, Mobile e API.

Meu objetivo é contribuir para a qualidade de produtos digitais por meio da identificação de falhas, análise de riscos e Análise de Root Cause (causa raiz).
